## 修复：推送 Gitee 失败 (shallow update not allowed)
- 项目本地仓库是 `github.com/chengaopan/AutoMergePublicNodes` 的浅克隆，浅层边界在 `146fff0`，其父 `074f108e` 本地缺失。
- 推送到 `https://gitee.com/Lyin811/auto-merge-public-nodes.git` 时报 `shallow update not allowed`；远程当时为空仓库（无 master 分支），所以前面的 fetch 报 `couldn't find remote ref refs/heads/master` 只是空仓库的副现象。
- 修复步骤：
  1. 用 `git commit-tree` 以 `146fff0` 的文件树建新根提交 `bec0150`，以 `e55ee90` 的文件树建子提交 `eaa1ccc`（保留最近两次快照的内容）。
  2. `git reset --soft eaa1ccc` 让 master 指向新链。
  3. 删除仍指向浅层 `146fff0` 的过期远程跟踪引用 `refs/remotes/master/*`。
  4. 删除 `.git/shallow`，并 `git reflog expire --expire=now --all` + `git prune --expire=now` 清除游离断链提交。
- 结果：仓库不再浅层（`is-shallow-repository: false`），`git fsck` 干净，对象可完整打包（`git pack-objects` 退出 0）。
- 注意：浅克隆点之前（GitHub 上的）历史未包含，仅保留最近两次快照；当前代码完整保留。
- 沙箱无 Gitee 凭证，最终上传需用户在 IDE 中点 Push（其环境已配好账号）。
- 如需完整历史：可 `git remote add upstream https://github.com/chengaopan/AutoMergePublicNodes.git` 后 `git fetch --unshallow upstream`（需联网到 GitHub）。
